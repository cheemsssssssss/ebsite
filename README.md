# IE LaTeX 公式编辑器 (IE LaTeX Formula Editor)

专业强大的在线 LaTeX 数学公式编辑器与转换工具。支持 KaTeX/MathJax 实时渲染、符号键盘可视化输入、Word MathML 原生公式直接复制、多倍率高清 PNG 与无损矢量 SVG 导出。

## 🌟 核心特性

- **上下结构工作台**：
  - **输入区域**：可视化 9 大类数学符号键盘（基础、微积分、希腊字母、矩阵、集合、箭头、函数、量子等）+ LaTeX 源码编辑区（支持拖拽自由拉伸调节高度、格式美化、字数统计）。
  - **输出区域**：实时高清公式渲染画布（字号调节、行间/行内模式、透明/纯白/深色/暖米底色）。
- **多格式导出与快捷转换**：
  - **输出图片 ⌃**：下载 1x-8x 超清无损 PNG 图片、下载矢量 SVG 文件、复制 SVG 源码。
  - **输出代码 ⌃**：复制纯 LaTeX 源码、Markdown 块级（`$$...$$`）、Markdown 行内（`$...$`）、HTML 嵌入代码。
  - **输出Word文件 ⌃**：复制 Word MathML（Word/WPS 直接 `Ctrl+V` 转原生可编辑公式）、下载 Word (.doc/.docx) 公式文档、下载 MathML (.mml) 文件。
  - **转义 ⌃**：自动将中文包裹为 `\text{...}`、美化排版与整理空格、压缩为单行公式、转义特殊字符。
  - **分享 ⌃**：复制公式分享链接、复制 Base64 Data URI。
- **经典公式库与历史记录**：预置高斯积分、欧拉公式、薛定谔方程等经典公式，支持自动保存与历史恢复。
- **国际化与主题**：支持中英文一键切换（`🌐 中 / EN`）与深色 / 浅色主题切换。

## 🚀 运行方式

本项目为纯静态前端架构，无需复杂后端依赖：

1. 直接在任意现代浏览器中双击打开 `index.html` 即可使用。
2. 或使用任意本地 HTTP 静态服务器（如 VS Code Live Server、Python 等）：
```bash
python -m http.server 8080
```
访问 `http://localhost:8080` 即可开始使用。
