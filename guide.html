一、LaTeX 数学公式基础结构与定界符

在 LaTeX 中，数学公式主要分为两类呈现模式：

  • 行内公式 (Inline Math)： 嵌入在文本段落中，高度紧凑，通常使用单美元符号 $...$ 或 \(...\) 包裹；
  • 行间独立块级公式 (Display Math)： 单独占据一行并居中显示，字体与符号尺寸舒展，通常使用双美元符号 $$...$$ 或 \[...\] 包裹。

二、高频基础语法与代码对照

三、高等数学与微积分排版实战

1. 极限与求和

在极限与求和中，下标会自动显示在符号正下方（Display 模式下）：

% 极限定义
\lim_{x \to 0} \frac{\sin x}{x} = 1

% 级数求和公式
\sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6}

2. 定积分、多重积分与微分算子

积分符号使用 \int，重积分使用 \iint 或 \iiint，回路积分使用 \oint。建议在微分算子 dx 前加上薄空格 \,，符合标准出版规范：

% 高斯积分 (经典微积分公式)
\int_{-\infty}^{+\infty} e^{-x^2}\,dx = \sqrt{\pi}

% 封闭曲面积分 (高斯散度定理)
\oint_{\partial V} \mathbf{F} \cdot d\mathbf{S} = \iiint_V (\nabla \cdot \mathbf{F})\,dV

四、线性代数与矩阵方程排版

LaTeX 排版矩阵推荐使用标准环境：

  • pmatrix：圆括号矩阵 (...)
  • bmatrix：方括号矩阵 [...]
  • vmatrix：行列式 |...|
  • cases：分段函数或方程组大括号
% 旋转矩阵示例 (bmatrix)
\begin{bmatrix}
  \cos\theta & -\sin\theta \\
  \sin\theta &  \cos\theta
\end{bmatrix}

% 经典分段函数 (cases)
f(x) = \begin{cases}
  x^2, & \text{当 } x \ge 0 \\
  -x,  & \text{当 } x < 0
\end{cases}

七、常见 LaTeX 语法错误与故障排查指南 (FAQ & Troubleshooting)

在编写数学公式时，遇到 KaTeX / MathJax 报错通常由定界符冲突、花括号未闭合或特殊字符引起。以下整理了学术研究中最常见的八大报错原因与一键解决办法：

报错 1 KaTeX parse error: Can't use function '$' in math mode

【常见诱因】 从 ChatGPT、Claude、Markdown 文档或论文源码中复制公式时，外层常带有 $$...$$ 或 $...$，直接粘贴进本编辑器导致重复嵌套。

【原因分析】 本编辑器已默认处于数学排版环境，再次遇到 $ 符号会被 KaTeX 当作非法字符解析。

【错误示范】 $$\int_0^1 x^2\,dx$$ 或 $E=mc^2$

【正确写法】 \int_0^1 x^2\,dx 或 E=mc^2（删除首尾外层的一对或两对美元符号即可）。

【智能特性】 本编辑器内置自适应脱壳算法，通常会自动清除首尾 $$；若在其他平台请手动移除。

报错 2 KaTeX parse error: Expected '}', got 'EOF' (花括号未闭合)

【常见诱因】 在书写分式 \frac{}{}、开根号 \sqrt{} 或复杂指数时，漏掉了末尾的闭合大括号 }。

【原因分析】 LaTeX 语法强制要求所有作为参数的分组大括号必须成对闭合。解析器读到公式尾端（EOF, End of File）仍未找到配对的 } 就会报错。

【错误示范】 \frac{a + b}{c + \sqrt{d} （最后缺少一个 }）

【正确写法】 \frac{a + b}{c + \sqrt{d}}

【排查技巧】 关注编辑器光标处的高亮括号配对提示，由内向外检查 { 与 } 的数量是否完全相等。

报错 3 Double superscript 或 Double subscript (多重上下标冲突)

【常见诱因】 连续使用两个上标符号 ^ 或两个下标符号 _，例如键入 x^2^3 或 a_i_j。

【原因分析】 LaTeX 无法推断结合优先级（是 $(x^2)^3$ 还是 $x^{(2^3)}$？），因此禁止连续多重上下标。

【错误示范】 x^2^3 或 a_1_2

【正确写法】 必须明确使用大括号分组：x^{2^3} 或 (x^2)^3；双下标应写为 a_{i,j} 或 {a_i}_j。

报错 4 KaTeX parse error: Undefined control sequence: \xxx (未定义命令)

【常见诱因】 公式中出现未识别的反斜杠指令，渲染器提示命令不存在。

【原因分析】 90% 属于命令单词拼写错误；另外 10% 属于生僻宏包（如特定物理或电路包）在轻量 Web 渲染器中未内建。

【常见拼写纠错速查】

  • 无穷大：正确为 \infty（勿拼为 \infinty）
  • 偏微分算子：正确为 \partial（勿拼为 \part）
  • 小于等于：正确为 \le 或 \leq（勿拼为 \le=）
  • 大于等于：正确为 \ge 或 \geq（勿拼为 \ge=）
  • 希腊字母 α：正确为 \alpha（勿拼为 \alfa）

报错 5 KaTeX parse error: \left and \right mismatch (定界符不配对)

【常见诱因】 使用自适应伸缩括号 \left( ... \right) 或分段函数 \left\{ ... 时，漏写了配对的 \right。

【原因分析】 每一个 \left 必须对应一个 \right。如果公式只需要单侧括号（如分段函数只有左大括号，或微积分代入线只有右侧竖线），另一侧必须使用虚拟占位点 \right. 或 \left.！

【错误示范】 代入线只写 \frac{df}{dx} \right|_{x=0}（前面缺少 \left.）

【正确写法】 \left. \frac{df}{dx} \right|_{x=0}，或直接使用单侧尺寸宏：\frac{df}{dx} \Big|_{x=0}。

报错 6 中文汉字显示为方块、红字或排版错乱

【常见诱因】 在公式中直接键入汉字或全角符号，例如 E = mc^2 (质能方程)。

【原因分析】 LaTeX 数学模式默认将所有连续英文字符当作数学变量斜体解析，未声明环境的非 ASCII 汉字会导致解析异常。

【错误示范】 f(x) = x^2 \quad 当 x > 0

【正确写法】 将汉字放入 \text{...} 文本环境中：f(x) = x^2 \quad \text{当 } x > 0。

【一键技巧】 直接点击本编辑器底部的【转义 ⌃】➔【自动包裹中文为 \text{}】，系统将全自动识别并规范包裹所有中文！

报错 7 百分号 %、下划线 _、与号 & 导致公式被吞

【常见诱因】 公式中包含 85%、file_name 或 A & B，结果 % 后面的内容全部消失。

【原因分析】 在 LaTeX 中，% 是行内注释符（其后所有字符被当作注释忽略），_ 是下标引导符，& 是表格对齐符。

【正确写法】 必须添加反斜杠转义：百分号写为 85\%，文本下划线写为 \text{file\_name}，与号写为 \text{A \& B}。

报错 8 复制到 Word / WPS 中显示为纯代码，无法变成原生公式

【常见诱因】 用户误点了“复制源码”，然后直接去 Word 中按 Ctrl+V，粘贴出一串普通文本代码。

【正确操作流程】

  1. 在本编辑器底部操作栏，点击 【输出Word文件 ⌃】 下拉菜单；
  2. 点击 【复制 Word MathML】；
  3. 切换到 Word / WPS 文档，在目标位置直接按下 Ctrl + V（Mac 用户按 Cmd + V）；
  4. Word 会自动调用内置的 Office Math 解析器，瞬间将其转化为原生可编辑的数学公式对象！

1. LaTeX Formula Structure & Math Mode Delimiters

LaTeX equations are rendered in two fundamental display modes:

  • Inline Math: Embedded directly within a sentence paragraph. Typically wrapped with single dollar signs $...$ or \(...\);
  • Display Math: Positioned on an isolated line, centered with generous padding and expanded symbols. Wrapped with double dollar signs $$...$$ or \[...\].

2. High-Frequency Syntax & LaTeX Code Cheatsheet

Superscript & Exponents x^{2} or e^{i\pi} Group multi-character exponents inside braces {...}, e.g. x^{10}
Subscript & Indices a_{i,j} or x_{k+1} Multi-character subscripts must be grouped in curly braces
Standard Fractions \frac{numerator}{denominator} e.g. \frac{a + b}{c - d}; use \tfrac for inline compact height

3. Advanced Calculus & Analysis Workflows

1. Limits & Infinite Summations

Limits and sums automatically place bounds underneath operators in display mode:

% Limit definition
\lim_{x \to 0} \frac{\sin x}{x} = 1

% Infinite series summation
\sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6}

2. Integrals & Differential Operators

Use \int for single integrals, \iint for double integrals, and \oint for contour integrals. Add a thin space \, before differential operators like dx:

% Gaussian Integral (Euler-Poisson Integral)
\int_{-\infty}^{+\infty} e^{-x^2}\,dx = \sqrt{\pi}

% Divergence Theorem (Gauss-Ostrogradsky)
\oint_{\partial V} \mathbf{F} \cdot d\mathbf{S} = \iiint_V (\nabla \cdot \mathbf{F})\,dV

4. Linear Algebra, Matrices & Piecewise Systems

Standard matrix environments provided by AMS-LaTeX:

  • pmatrix: Parenthesized matrix (...)
  • bmatrix: Bracketed matrix [...]
  • vmatrix: Determinant bars |...|
  • cases: Piecewise functions or simultaneous equation braces
% Rotation Matrix (bmatrix)
\begin{bmatrix}
  \cos\theta & -\sin\theta \\
  \sin\theta &  \cos\theta
\end{bmatrix}

% Piecewise Function (cases)
f(x) = \begin{cases}
  x^2, & \text{if } x \ge 0 \\
  -x,  & \text{if } x < 0
\end{cases}

7. Common LaTeX Parse Errors & Troubleshooting (FAQ)

When authoring mathematical equations, KaTeX and MathJax errors typically stem from delimiter conflicts, unclosed brackets, or reserved characters. Here are the top eight most common syntax errors and their solutions:

Error 1 KaTeX parse error: Can't use function '$' in math mode

Cause: Outer math delimiters like $$...$$ or $...$ were copied from ChatGPT, Claude, or Markdown and pasted into an already active math rendering context.

Incorrect: $$\int_0^1 x^2\,dx$$ or $E=mc^2$

Correct: \int_0^1 x^2\,dx or E=mc^2 (Simply remove the outer dollar signs).

Smart Feature: Our online editor includes automatic delimiter unwrapping to strip redundant outer dollar signs on the fly.

Error 2 KaTeX parse error: Expected '}', got 'EOF' (Unclosed Curly Brace)

Cause: A closing curly brace } was omitted inside nested commands such as \frac{}{} or \sqrt{}.

Incorrect: \frac{a + b}{c + \sqrt{d} (Missing final closing brace })

Correct: \frac{a + b}{c + \sqrt{d}}

Fix: Inspect bracket pairs from inside out to ensure that every opening { has a matching }.

Error 3 Double superscript or Double subscript

Cause: Consecutive superscript ^ or subscript _ operators were used without explicit grouping.

Incorrect: x^2^3 or a_i_j

Correct: Explicitly clarify associative order with braces: x^{2^3} or (x^2)^3; for subscripts use a_{i,j} or {a_i}_j.

Error 4 KaTeX parse error: Undefined control sequence: \xxx

Cause: A typo occurred in the LaTeX macro name, or the command belongs to an esoteric non-standard package.

Quick Fix Cheatsheet:

  • Infinity: use \infty (not \infinty)
  • Partial derivative: use \partial (not \part)
  • Less than or equal: use \le or \leq (not \le=)
  • Greek letter α: use \alpha (not \alfa)
  • Empty set: use \emptyset or \varnothing

Error 5 KaTeX parse error: \left and \right mismatch

Cause: Every scalable delimiter \left must be matched by a corresponding \right. If you only need a delimiter on one side (e.g., evaluation bar or piecewise brace), you must balance the other side with a virtual dot delimiter \right. or \left..

Incorrect: Evaluation bar written as \frac{df}{dx} \right|_{x=0} (Missing opening \left.)

Correct: \left. \frac{df}{dx} \right|_{x=0}, or use the single-sided vertical bar macro: \frac{df}{dx} \Big|_{x=0}.

Error 6 Plain / Non-ASCII Text Appearing as Corrupted or Spaced Letters

Cause: LaTeX treats all consecutive ASCII letters as products of single mathematical variables in italics. Non-ASCII or regular words must be wrapped in a text environment.

Incorrect: f(x) = x^2 \quad for x > 0

Correct: f(x) = x^2 \quad \text{for } x > 0

Tip: In our editor, click 【Escaping ⌃】➔ 【Auto-wrap Chinese into \text{}】 to format automatically.

Error 7 Percent %, Underscore _, or Ampersand & Truncating Code

Cause: In LaTeX syntax, % denotes an inline comment that discards everything following it on that line. _ is a subscript operator, and & is an alignment separator.

Correct: Escape reserved symbols with a leading backslash: write 85\%, \text{file\_name}, and \text{A \& B}.

Error 8 Pasted into Word / WPS as Raw Code Instead of Native Equation

Cause: Copying raw LaTeX text directly into Word produces plain text strings.

Standard Workflow:

  1. In our editor, open the 【Export Word ⌃】 menu and click 【Copy Word MathML】;
  2. Switch to Microsoft Word or WPS and press Ctrl + V (or Cmd + V on Mac);
  3. Word's internal Office Math parser automatically converts the XML payload into an interactive, native equation object!
