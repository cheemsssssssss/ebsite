关于我们 (About Us)

平台名称：IE LaTeX 公式编辑器 (IE LaTeX Formula Studio) 使命愿景：让数学公式排版变得优雅、高效与触手可及

项目使命： IE LaTeX 公式编辑器创立于 2026 年，旨在为广大学生、科研学者、数学教师与工程技术人员提供一个开箱即用、无门槛、零延迟且绝对尊重学术隐私的现代化在线 LaTeX 数学公式工作台。

1. 创立背景：解决数学排版的现实痛点

在日常学术研究、毕业论文撰写、课件 PPT 制作与在线答疑中，复杂的数学与物理公式排版往往伴随着繁琐的门槛：

  • 传统桌面 LaTeX 发行版（如 TeXLive / MacTeX）动辄数个 G 空间，编译速度缓慢，配置环境变量与宏包极其繁琐；
  • 传统在线编辑器往往需要注册登录、强制收费、依赖后端云服务器网络请求，响应延迟高，且存在敏感未公开科研数据被服务端留存的风险；
  • Word 与 LaTeX 之间的割裂：在写毕业论文或学术报告时，难以把 LaTeX 优雅快速地转化为 Word / WPS 的原生可编辑数学公式对象。

为了解决上述痛点，IE LaTeX 公式编辑器应运而生。我们坚持纯前端计算理念，让公式编辑与转换变得轻盈而自由。

2. 核心技术优势与架构

IE LaTeX 公式编辑器依托现代 Web 前端前沿标准打造，具备四大关键技术支撑：

  • KaTeX + MathJax 双核引擎架构： 采用 Khan Academy 的 KaTeX 超高速排版引擎作为默认渲染器，实现输入到输出的毫秒级同步显示；辅以 MathJax 矢量转换内核，提供对复杂张量、狄拉克符号（Dirac notation）及高级化学式的无死角支持。
  • 智能定界符脱壳 (Smart Unwrapping)： 针对用户从 ChatGPT、学术论文、Markdown 笔记中复制公式常常携带 $$ ... $$ 或 \[ ... \] 定界符从而导致传统渲染器报错的常见问题，内置自适应脱壳算法，即贴即排。
  • 原生 MathML 双向桥接： 严格遵循 W3C MathML 3.0 推荐标准，生成包含标准命名空间与语义层级的 XML 数据流，使 Microsoft Word / WPS 能够原汁原味将其转化为原生公式，免去手工二次重输之苦。
  • 4K / 8K 高倍率矢量光栅化： 基于 HTML5 Canvas 与 SVG 纯矢量路径重构，支持从 1x 网页清晰度直到 8x 印刷级海报超清图片的即时无损导出。

3. 坚持纯客户端运算：学术数据零泄露

我们坚信，学术推导、未发表的论文草稿以及考试原创命题属于用户的核心智力资产。因此，从系统底层设计之初，IE LaTeX 公式编辑器就确立了“无后端暂存”原则：

您的所有公式录入、字符统计、图像生成均运行在您本机的 JavaScript 运行时环境中。即使断开互联网连接，工具核心排版功能依然能够稳定运行。我们绝不在任何云端数据库中保存您的公式内容。

About Us

Platform: IE LaTeX Formula Studio Mission: Making mathematical typesetting elegant, accessible, and ultra-fast

Our Mission: Founded in 2026, the IE LaTeX Formula Editor is dedicated to providing students, researchers, mathematics educators, and software engineers with an instant, zero-latency, and 100% privacy-respecting modern web environment for LaTeX mathematical typesetting.

1. Origin: Overcoming Mathematical Publishing Pain Points

Typesetting mathematical, physical, and chemical formulas during thesis writing, conference presentations, and lecture preparation has traditionally been cumbersome:

  • Bulky desktop TeX distributions (TeXLive, MacTeX) occupy gigabytes of storage, require complex environment setup, and suffer from slow compilation cycles;
  • Traditional cloud editors frequently require user registration, charge high subscriptions, rely on slow backend servers, and risk leaking sensitive unreleased research data;
  • Disconnection between Word and LaTeX: Authors writing dissertations in Microsoft Word or WPS often struggle to import LaTeX code into native, editable equation objects.

To eliminate these roadblocks, IE LaTeX Formula Editor was created. We embrace client-side computing to keep mathematical formatting effortless, instantaneous, and freely accessible.

2. Core Technical Architecture

Engineered with modern Web standards, IE LaTeX Formula Editor is powered by four primary technical pillars:

  • Dual-Engine Synergy (KaTeX + MathJax): Leverages Khan Academy's KaTeX for sub-millisecond typing responsiveness, backed by MathJax for advanced tensor notation, Dirac bra-ket states, and chemical mhchem symbols.
  • Smart Delimiter Unwrapping: Automatically strips outer wrappers such as $$ ... $$ or \[ ... \] copied from AI tools or Markdown editors, eliminating syntax errors before parsing begins.
  • Native Word MathML Bridge: Generates W3C-compliant MathML 3.0 XML that can be pasted directly into Microsoft Word and WPS via Ctrl + V as native, interactive equations.
  • 4K / 8K High-DPI Vector Rasterization: Re-renders formulas onto scalable HTML5 Canvas and clean SVG vector paths, enabling lossless exports up to 8x resolution for journal publication and academic posters.

3. Strict Local Client-Side Computing: Zero Data Leakage

We firmly believe that preliminary equations, unreleased proofs, and exam questions are valuable intellectual property. Our platform is built on an absolute Zero-Cloud-Storage policy:

Every formula keystroke, character count, and image generation runs entirely within your device's browser sandbox. Your formulas are never transmitted or stored on any external server. The editor remains fully functional even in offline environments.
